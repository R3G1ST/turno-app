# Turno — график кальянной для macOS

Нативное приложение для macOS: график смен, выручка за день, расчёт зарплаты с надбавками за пороги выручки.

## Возможности

- **График на месяц** — полная сетка «сотрудники × дни»: смены (утро/вечер/полная) цветом, выходные всегда видны. Шаблоны заполнения: 2 через 2, 3 через 1, 5 через 2, 6 через 1. Копирование недели.
- **Выручка за день** — ввод дневной выручки (кальянная + бар), автоматический расчёт надбавок.
- **Надбавки за пороги** — настраиваемые пороги: «выручка ≥ 30 000 ₽ → +300 ₽ каждому на смене». Пороги редактируются в Настройках.
- **Зарплата** — ведомость по месяцам: смены + ставки + надбавки = итог. Экспорт **PDF** и **CSV**, печать.
- **Сотрудники** — роли: кальянщик, официант, администратор, повар. Цвет роли, индивидуальная ставка.
- **Автообновления** — проверка GitHub Releases, обновление в один клик. Данные не затрагиваются.
- **Данные** — локально в `~/Library/Application Support/Turno`, резервные копии (последние 10) одной кнопкой.

## Установка

Скачайте `Turno-x.y.z.dmg` из [Releases](https://github.com/R3G1ST/turno-app/releases), откройте и перетащите **Turno** в **Applications**.

## Сборка из исходников

```bash
# .app
Scripts/build-app.sh      # → build/Turno.app

# DMG-установщик
Scripts/make-dmg.sh       # → build/Turno-<версия>.dmg

# Иконка (генерация Resources/Turno.icns)
swift Scripts/make-icon.swift
iconutil -c icns <путь>/turno-iconset -o Resources/Turno.icns
```

Требуется macOS 14+, Xcode Command Line Tools (Swift 6+).

## Стек

Swift 6 · SwiftUI · PDFKit · AppKit · JSON-хранилище · без сторонних зависимостей.

## Выпуск новой версии

1. Поднимите `CFBundleShortVersionString` в `Resources/Info.plist`.
2. `Scripts/build-app.sh && Scripts/make-dmg.sh`
3. Создайте GitHub Release с тегом `vX.Y.Z` и приложите `Turno-X.Y.Z.dmg`.
4. Приложение само предложит обновление пользователям.
